Drag a video to another day; drag one from "Not planned" onto a day to plan it. Click a video to open its tree (2) or its plan (3).

4. Telling an agent the plan

You say the plan in words; the agent writes it with one Library command per video, and you see it on the calendar. For example:

"Part 1's Shorts: one every two days from Monday, all four platforms, 7 pm."

planRelease {item: Part 1, video: "AI can build the UI…", day: 2026-10-19, clock: "19:00", platforms: [youtube, instagram, x, linkedin]}
planRelease {item: Part 1, video: "Why designers should…", day: 2026-10-21, clock: "19:00", platforms: [youtube, instagram, x, linkedin]}
