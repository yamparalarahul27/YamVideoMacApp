A calmer way to edit.

Try the proposed YamVideo interface.

  1. Start with colour. Switch between Original and Corrected, then drag the Compare divider or adjust the four sliders.
  2. Make a cut. Click the timeline ruler to seek, then Split. Select a section to change its speed in Edit.
  3. Edit together. Open Local agents and try a Codex or Claude edit. Undo it with the toolbar or ⌘Z.
  4. Explore later effects. Add a timed blur from Effects, then adjust its strength.
  5. Finish in Export. Review the separate export sheet without cluttering the inspector.

Illustrated sample frames, simulated playback and CSS colour changes. No real media processing, LUT conversion or agent connection. Changes reset on reload.
