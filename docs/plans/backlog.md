## Project files and older builds (added 2026-10-20)

From the timeline gaps change ([PR #64](https://github.com/yamparalarahul27/YamVideoMacApp/pull/64)),
which made projects version 21. The owner asked to track it, not change anything yet.

- A new build opens every older project as it is. A project file changes only when it is
  saved.
- A project saved by a new build cannot be opened by an older build ("This project was
  saved by a newer version of YamVideo") until that Mac pulls and rebuilds.
- The published projects (AppStore Learnings on the Yamparala Mac, the projects on the
  Equicom Mac) stay as they are. Do not save them from a new build until both Macs have
  pulled.
- To decide later: save each project at the lowest version that holds what it uses (a
  project with no gaps could stay version 20), or let an older build open a newer file
  to read only.
